# 🤖 JARVIS AI ASSISTANT

An AI-powered local voice assistant inspired by Iron Man’s JARVIS, built using Python, Ollama, speech recognition, and desktop automation.

JARVIS can understand voice commands, respond using AI, open desktop applications, automate browser tasks, and operate fully offline using local LLMs.

---

# 🚀 Features

- 🎤 Voice-controlled AI assistant
- 🧠 Local AI using Ollama + Llama3
- 🔊 Text-to-speech responses
- 🗣 Custom wake words
- 💻 Desktop application control
- 🌐 Browser automation
- 🧠 Memory system
- ⚡ Real-time speech recognition
- 🔒 Offline AI processing
- 🍎 macOS support

---

# 🧠 Tech Stack

| Technology | Purpose |
|------------|---------|
| Python | Core development |
| Ollama | Local AI runtime |
| Llama3 | Language model |
| SpeechRecognition | Voice recognition |
| pyttsx3 | Text-to-speech |
| Requests | API communication |
| OpenWakeWord | Wake word detection |
| macOS Automation | Desktop control |
